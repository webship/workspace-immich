# @webship.co/workspace-immich

Immich for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that makes an Immich
library from its release and serves it from containers of its own (its server, its Postgres with the vector extensions
and its valkey beside it, machine learning off), the Immich step pack wired into the workspace's testing setup of that
library, and its AI items. The workspace is container-based (DDEV by default).

The builder, the tests and CI come with the first release, `1.0.0`.
